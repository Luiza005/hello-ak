# 🧡 Hello AK — интерактивный HTTP-сервер

Go-сервер с HTML-страницей, где имена 34 участников образуют большое сердце. Можно отправлять сердечки участникам и наблюдать за общей статистикой.

## Запуск

1. Установите [Go](https://go.dev/dl/).
2. Откройте папку проекта в терминале.
3. Запустите `go run .`.
4. Перейдите на http://localhost:8080.

Для остановки сервера нажмите `Ctrl + C`.

## HTTP API

- `GET /` — HTML-страница с сердцем.
- `GET /api/hearts` — JSON со статистикой сердечек.
- `POST /api/hearts` — добавить сердечко участнику. JSON-тело запроса: `{"name":"Балаян Луиза"}`.
- `POST /api/reset` — сбросить все сердечки (кнопка на странице с подтверждением).

Сервер отвечает кодами `200 OK`, `400 Bad Request`, `404 Not Found` и `405 Method Not Allowed` в соответствующих ситуациях.

Браузер делает реальные `fetch`-запросы к Go-серверу. Посмотреть запросы и ответы можно в инструментах разработчика: **F12 → Network**. Чтобы увидеть обновление счётчиков между вкладками, откройте страницу в двух вкладках: каждая обновляет статистику каждые пять секунд.

Кнопка «Сбросить сердечки» обнуляет счётчики у всех участников и перезаписывает сохранённую статистику. В учебной версии этот API не защищён авторизацией, поэтому не следует открывать его для посторонних без дополнительной защиты.

Статистика сохраняется в локальном файле `hearts.json`, который создаётся автоматически и не загружается в GitHub благодаря `.gitignore`. Приложение запускается локально; чтобы другие пользователи могли обращаться к серверу, потребуется отдельно разместить его в сети.

Технологии: Go (`net/http`, `encoding/json`, `sync`), HTML, CSS, JavaScript.
