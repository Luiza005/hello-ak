# 🧡 Hello AK — HTTP Server

Простой HTTP-сервер на Go с интерактивной веб-страницей.

## О проекте

Приложение запускает локальный HTTP-сервер, который отображает в браузере анимированное оранжевое сердце с приветствием «Привет, AK!».

Вокруг центрального сердца расположены имена 34 участников, образующие контур большого сердца.

## Технологии

- **Go** — создание HTTP-сервера
- **HTML** — структура веб-страницы
- **CSS** — оформление и анимации
- **net/http** — стандартная библиотека Go для обработки HTTP-запросов

## Как запустить

Для запуска необходимо установить [Go](https://go.dev/dl/).

1. Скачайте проект с GitHub.
2. Откройте папку проекта в терминале.
3. Выполните команду `go run .`
4. Откройте в браузере http://localhost:8080

## Возможности

- Обработка HTTP-запросов на порту 8080
- Отображение HTML-страницы
- Анимация пульсирующего сердца
- Формирование сердца из имён участников
- Подсветка имён при наведении курсора

## Остановка сервера

Для остановки нажмите `Ctrl + C` в терминале.
